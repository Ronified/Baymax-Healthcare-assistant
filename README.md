
# Baymax Healthcare Assistant 🏥🤖
An AI-powered healthcare assistant inspired by Baymax from *Big Hero 6*. It helps users track health parameters, give medical tips, and provide first-aid guidance using Natural Language Processing (NLP) and Machine Learning models.

---

## 📌 Features
✅ Symptom Checker – Get basic insights on symptoms  
✅ Health Monitoring – Track your vitals and lifestyle data  
✅ First Aid Guidance – Quick solutions for common emergencies  
✅ User-Friendly Chat Interface – Talk to Baymax just like a friend  
✅ Lightweight & Open-Source  

---

## 🚀 Getting Started
### 1. Clone the Repo
```bash
git clone https://github.com/Ronified/Baymax-Healthcare-assistant.git
cd Baymax-Healthcare-assistant
```

### 2. Install Dependencies
```bash
pip install -r requirements.txt
```

### 3. Run the Application
```bash
python app.py
```

Then open your browser and go to:  
👉 http://127.0.0.1:5000
